# 合同誌あとがきメーカー
<img width="1427" height="1028" alt="image" src="https://github.com/user-attachments/assets/79a5ea97-234a-4188-889d-35d3e5947aee" />

## 概要
- windows用です
- しつびのNFイラスト合同誌用に最適化しています
- テンプレ画像の作成と、回収した画像の配置がこのソフトで可能です

ダウンロードは[こちら](https://github.com/pwxwx/AtogakiMaker/releases)

## 使い方
### 1. サイズ情報を入力
 - 「1. テンプレート作成」タブで、以下を入力します。
   - 完成サイズ：塗り足しを切り取ったあとの、実際に完成品として届くサイズです
   - 塗り足し：上下左右ひとつあたりの塗り足しです。すべて同じ値が適用されます。
   - ページ内余白 上下：テンプレ枠を配置する際の上下ひとつあたりのマージンです。
   - ページ内余白 左右：テンプレ枠を配置する際の左右ひとつあたりのマージンです。
   - 画像間余白 左右：テンプレ枠とテンプレ枠の間の隙間です。
   - 解像度：解像度です。
   - 参加人数：複数ページにまたがる際のプレビュー用で、実際の人数はステップ4で入力した画像数となります。
   - 枠数：テンプレ枠の配置です。
   - 奥付テキスト：行数に応じて自動でテキストサイズが変わります。

 - デフォルトでは、A4/塗り足し5mmの設定になっています。
 - 横枠数・縦枠数は参加人数が上手いこと収まるように調整してください。余ったスペースに編集後記などを書いても良いと思います。

### 2. テンプレ画像の書き出し
 - 「レイアウトイメージを更新」を押すと、ステップ1で入力した値にそって全体のイメージが更新されます。
 - 「テンプレート画像を保存」でテンプレ画像(一人が書く分)が保存されます。
 - 書き出し後にサイズを書き換えてしまうと、ステップ4でサイズが合わなくなることがあるので、**ここから完成まではサイズを変更しないことを推奨します**。
   - データはjsonファイルとして保存されているので、ソフトを閉じてもデータは失われません。

### 3. みんなに配ってあとがきを書いてもらう
 - ステップ2で作った画像を参加者に送り、あとがきを書いて提出してもらいます。
 - その際、画像の名前を「(ハンドルネーム)_あとがき」などにしておいてもらうと、あとで並び替えが楽です。
 - 回収した画像は、一つのフォルダにまとめておくと一括で入力できます。

### 4. 完成画像の書き出し
 - 「2. ページ合成」タブに移動し、ステップ3で集めたフォルダから画像を一括追加します。
 - ファイル単位で画像を追加することもできます。
 - 追加後、「上へ」「下へ」ボタンで並び替えられるほか、担当ページを記載できます。
 - 担当ページは**自動で連番が振られる**ので、一番上から入力していくと楽です。
 - 複数ページ担当している人がいる場合は、例えば「3-5」のように入力すると、その下の行が自動で「6」からの連番になります。
 - 「プレビューを更新」を押すと、右のプレビューが更新されます。「完成画像の保存」で、プレビュー通りの画像が保存されます。

### 5. アレンジ(任意)
 - 本ソフトは機能を最低限にしています。他のペイントソフトなどで読み込んでデザインを変えたり、編集後記を載せるなど、自由にカスタマイズしてください。
